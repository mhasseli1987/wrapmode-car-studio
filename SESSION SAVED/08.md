## ۲) روان‌سازی اسکرول (کار اصلی این سشن)

کاربر گفت: «اسکرول خشک گیر داره».

### ۱۰ ریشه‌ی خشکی و رفع هرکدام

| # | ریشه | رفع |
|---|---|---|
| ۱ | **دو حلقهٔ موازی**: `gsap.ticker` + `setInterval(33ms)` هر دو `step()` را صدا می‌زدند | `setInterval` کامل حذف شد؛ تک‌حلقه با fallback به rAF بومی |
| ۲ | **easing وابسته به فریمریت**: `smoothQ += d * 0.38` در ۱۲۰Hz دوبرابر ۶۰Hz سریع | میرایی نمایی: `alpha = 1 - Math.exp(-dt * k)` با `k = 9` |
| ۳ | **گام زمانی محافظت‌نشده** | `MAX_DT = 1/30` برای مهار جهش بعد از stall |
| ۴ | **layout thrash**: `scrollHeight`/`offsetHeight` هر فریم در حلقه | کش `scrollMax` + `ResizeObserver` روی `body` |
| ۵ | **resize بدون debounce** | هندلر با rAF-debounce |
| ۶ | **ری‌الوکیشن بافر canvas** هر فریم (`canvas.width=`) | کش `canvasW/canvasH` + early-return |
| ۷ | **prefetch حلقهٔ ۳۵تایی** هر فریم | گارد `if (Math.abs(idx - lastPrefetchIdx) < 6) return` |
| ۸ | **نوشتن مکرر DOM** (opacity/class/`--drift`/`scaleX`) | الگوی «آخرین مقدار» روی همه |
| ۹ | **Lenis با `duration: 0.95`** → حس کشدار/درگ‌دار | `lerp: 0.1` (موبایل ۰.۱۴) + `syncTouch: false` |
| ۱۰ | **زوم پرهرم سرعت‌محور** هر فریم | حذف شد (`ZOOM_OFF = 1`) |

# SESSION 01 — پاک‌سازی و شروع پروژه جدید Wrapmode (Scroll Experience)

تاریخ: ۲۰۲۶-۰۸-۲۴/۲۵

## خلاصه
1. کل پروژه قبلی wrapmode-car-studio (کد، git، reference) پاک شد.
2. ریپوی https://github.com/amirmushichge/tea-leaf-scroll-world به‌عنوان Base در همین پوشه کلون و کامیت اولیه شد. بیلد پاس.
3. معماری Base شناخته شد: استارتر **vinext** (Next.js روی Cloudflare/Vite)، React 19، Tailwind v4، بدون کتابخانه انیمیشن. هسته: `app/TeaJourney.tsx` — صفحه spacer با ارتفاع 650vh، صحنه fixed، ۵ کلیپ mp4 پیش‌بارگذاری (blob)، اسکرول → progress → اسکراب `currentTime` با lerp 0.16 در rAF، کراس‌فید ۱۰٪ انتهایی هر کلیپ. UI در `app/globals.css`.
4. مرحله ۲ انجام شد: `scenes` → ۴ ماشین، `clips` → ۳ placeholder (`/media/video/car-1-to-2.mp4` و…)، ۴ پوستر placeholder SVG در `public/media/stills/car-1..4.svg`. بیلد پاس.
5. مرحله ۳ انجام شد: تایم‌لاین ۷ واحدی hold/clip — `hold(car1)·clip1·hold(car2)·clip2·hold(car3)·clip3·hold(car4)`؛ در hold کلیپ قبلی روی فریم آخر ثابت؛ `jumpTo` به مرکز هر hold. بیلد پاس. (تغییرات کامیت نشده)
6. **تغییر معماری:** کاربر مسیر ویدیویی را کلاً کنار گذاشت → هدف: تجربه 3D interactive با مدل‌های ENZO.dev.

## معماری نهایی توافق‌شده (فقط تحلیل، هنوز کد ننوشته)
به‌ازای هر ماشین (۴ ماشین، پایان اسکرول روی ماشین ۴):
1. ماشین ساده و بدون طرح
2. با اسکرول، wrap به‌صورت cinematic روی بدنه ظاهر می‌شود (پیشنهاد: shader-based reveal با دو متریال و uniform از progress — wipe/dissolve جهت‌دار + texture واقعی wrap)
3. پنل محصول: اطلاعات، قیمت (تومان)، دکمه «افزودن به سبد خرید»
4. انتقال پیوسته دوربین به ماشین بعد (بدون cut)

## نیازمندی‌های فنی
- Three.js + React Three Fiber + Drei + GSAP (ScrollTrigger) — سازگار با vinext/Vite
- مدل‌ها: **GLB** ترجیح، Draco/meshopt، بدنه mesh جدا با نام مشخص (مثلاً `body`)، مقیاس متر، Y-up، pivot مرکز
- Wrap texture: تصویر png/svg → CanvasTexture یا shader mix

## وضعیت فایل‌ها
- `app/TeaJourney.tsx`: ویرایش‌شده برای ۴ ماشین + تایم‌لاین hold/clip (فعلاً video-based؛ با تغییر معماری بازنویسی می‌شود)
- `public/media/stills/car-1..4.svg`: پوسترهای placeholder
- git: یک کامیت پایه؛ مراحل ۲ و ۳ هنوز کامیت نشده

## قدم بعدی
شروع پیاده‌سازی 3D (R3F) پس از تأیید کاربر و دریافت/مسیر مدل‌های GLB از ENZO.dev
